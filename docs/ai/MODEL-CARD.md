# 模型卡（Model Card）· MedAssist AI 中台

> 对应评测 E6-30：系统此前只在代码里体现治理能力，没有可对外交付的模型卡与 AI 使用政策。
> 本文件是**对外交付与院内评审**用的单一事实源；模型/提示词变更须同步更新本文件与
> `agent_model_versions` 版本库。

| 项 | 内容 |
|---|---|
| 系统名称 | MedAssist 铭医 · 临床协同平台的 AI 辅助能力 |
| 文档版本 | v1.0（2026-11-13） |
| 定位 | **临床辅助工具，不构成诊断或处方决策，不替代医师判断**；当前不按 SaMD 申报 |
| 适用场景 | 文献循证问答、用药审查提示、影像/病例辅助解读、病历质控建议、多学科讨论材料整理 |
| 明确不适用 | 直接下达医嘱、自动签发诊断、替代知情同意、无医师复核的自动处置 |

## 1. 模型与供应商

| 能力域 | 运行模型（以运行时注册为准） | 供应商类型 | 合规要求 |
|---|---|---|---|
| 药物/用药（drug） | deepseek 系列（境内 API） | 境内 | 允许；不得发送 PHI |
| 文献循证（literature） | deepseek 系列 + 检索增强 | 境内 | 允许；引用必须来自检索证据 |
| 影像（imaging） | 多模态模型（按配置） | 境内优先 | 影像须去标识化后调用 |
| 病历质控（qc） | deepseek 系列 | 境内 | 只发送脱敏文本，结论仅作提示 |
| 病例/多学科（case/mdt） | deepseek 系列 | 境内 | 同上 |

**境外 provider 一律拒绝**：`backend/core/model_policy.py` 在建模前拦截；
检索联网只允许医疗学术/监管白名单域名。

## 2. 输入与输出边界

- **输入**：用户问题 + 检索到的院内/公开证据片段；不接收身份证号、手机号、住址等直接标识。
- **输出**：建议文本 + 引用来源 + 置信度 + 是否需要人工复核。
- **强制约束**：
  1. 任何 AI 结论均需医师/药师确认后才可进入病历或医嘱；
  2. 置信度低于阈值或命中"需复核"规则时必须显式标注；
  3. 无证据支撑时必须走兜底并声明"仅供参考"，不得伪造引用。

## 3. 已知局限

1. 模型可能生成看似合理但无证据的内容（幻觉），系统以"强制引用 + 兜底声明"缓解，不能消除；
2. 中文临床术语、罕见病、超说明书用药的覆盖有限；
3. 影像能力依赖上传质量与模型版本，不能作为独立诊断依据；
4. 置信度为模型自评，**不构成统计学意义上的概率校准**（ECE 见评测产物）。

## 4. 评测与监测

| 项 | 当前状态 | 说明 |
|---|---|---|
| 离线评测 | `scripts/run_eval.py` + `eval/results_*.json` | 已接入引用精确率、拒答正确率、ECE 三项指标与质量门槛 |
| 漂移监测 | `backend/agents/governance/drift.py` | 需持续积累真实流量快照后才具备判读意义 |
| 误报/不良事件 | `governance/incidents.py` + 工单 | 每例闭环、可复盘 |
| 版本可追溯 | `agent_model_versions` | 目标：任一输出可定位到模型/提示词版本（版本库与运行时绑定为强约束） |
| 临床验证 | 框架就绪，**真实研究未开展** | 需伦理批件 + ≥100 例双人独立标注（外部依赖） |

## 5. 变更与回滚

- 模型、提示词、检索策略的任何变更必须：登记版本 → 审批 → 灰度 → 观察指标 → 方可全量；
- 回滚以"切换 ACTIVE 版本"实现，不依赖重新部署；
- 破坏性变更（影响输出结构或安全阈值）须重新认证相关岗位并更新本文件。

## 6. 责任与联系

| 角色 | 职责 |
|---|---|
| 临床负责人 | 确认适用范围与禁忌、组织临床验证 |
| 平台负责人 | 模型/版本/提示词治理、漂移与事故响应 |
| 信息安全 | PHI 出境与合规审查、审计抽查 |
| 院方信息科 | 账号、权限、日志留存与对外口径 |

> 本模型卡不替代伦理批件、第三方临床验证报告与监管注册文件。

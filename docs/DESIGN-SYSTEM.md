# 铭医 MedAssist · 设计系统 v4「开放平面 / Open Plane」

> 适用：`frontend-console/`（对接 `/api/v2` 的临床控制台）。
> 目标：让人在 8 小时工作里**看得清、扫得快、敢下手**；不是让页面"像设计过"。

v4 不是 v3 的调色，而是把 v3 的“技能外观”全部拆掉。依据不是个人偏好，而是：

- `docs/skills-audit/full/08-taste-skill/references/app-screens.md`（23 个真实产品界面）
- `docs/skills-audit/full/08-taste-skill/references/tells.md`（生成式套路清单）
- `docs/skills-audit/full/09-impeccable/reference/craft-floor.md`
- `docs/skills-audit/full/17-web-design-guidelines/command.md`
- `docs/skills-audit/full/06-frontend-ui-engineering/references/accessibility-checklist.md`
- `docs/skills-audit/full/03-ui-ux-pro-max/references/quick-reference.md`

## 1. 五条底线

1. **颜色上数据，不上界面。** 中性地面 + 一个临床青绿，只给数据、状态与唯一主操作。
2. **一个屏幕回答一个问题。** 手术排台回答“哪间空着、下一台是什么”，所以时间轴是最大的东西。
3. **数字是数据，标签是语言。** 数字 tabular、右对齐；标签、表头、导航用正文体、句首大小写。
4. **安静不是空。** 删掉装饰后，用真实数据、完整字段、正确状态填满，而不是留白。
5. **手机是另一种编排。** 640px 以下表格变列表；导航折叠为全屏 sheet；页面绝不横向滚动。

## 2. 明确禁止（来自 tells.md / craft-floor.md）

- 眉标 / kicker / 小标签压在标题上
- `01 / 02 / 03` 编号（真实排序用 `<ol>`，不伪装成设计元素）
- 等宽字体当“技术感”标签（mono 只用于编码、时间、数字）
- 细线网格、刻度尺、裁切角、十字准星
- 奶油色/米黄地面 + 陶土/锈红强调
- 深色或饱和侧边栏（浅色产品界面 0/17）
- 带图标的 KPI 卡、KPI sparkline
- 卡片里套卡片
- 休息态卡片阴影、发光、玻璃/背景模糊
- 全大写 + 字距的表头
- 大号空态插画、shimmer 骨架
- 手机端把桌面表格/时间轴硬挤进 390px

## 3. 视觉语言

### 3.1 地面与表面

| 角色 | 浅色 | 深色 |
|---|---|---|
| 地面 `--ground` | `#F9FAFB` | `#000000` |
| 表面 `--surface` | `#FFFFFF` | `#111111` |
| 填充/悬停 `--raised` | `#F4F5F6` | `#222222` |
| 选中 `--active` | `#EEEEEE` | `#222222` |
| 边框 `--border` | `#E8E8E8` | `#1A1A1A` |
| 行分隔 `--rule` | `#F1F2F3` | `#161616` |
| 分隔线 `--control` | `#D1D5DB` | `#444444` |
| 控件边框 `--control-strong` | `#8E8E8E` | `#6E6E6E` |
| 主墨 `--text` | `#111111` | `#FFFFFF` |
| 次墨 `--muted` | `#5F6368` | `#B4B4B4` |
| 辅助 `--faint` | `#6B6B6B` | `#949494` |

- 表面靠 1px 边框或一层色调区分，**不同时用边框和阴影**。
- 阴影只给浮层：菜单、弹窗、toast。
- 深色是真实中性黑，不是 navy/slate。

### 3.2 唯一数据色

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--accent` | `#1F6F5C` | `#6FB39F` | 时间轴主数据、选中、焦点 |
| `--accent-weak` | `#E6F2EE` | `#142A24` | 已计划台次填充 |
| `--accent-ink` | `#123F34` | `#BFE4D8` | 强调文字 |
| `--positive` | `#247B50` | `#3FC07A` | 完成、正常 |
| `--negative` | `#C4242A` | `#E5566F` | 取消、失败 |
| `--warning` | `#92400E` | `#E5A93B` | 待处理、维护 |

强调色占比目标 ≤3–5%；一张屏只有一个主操作（近黑填充），其余是描边/文本按钮。

### 3.3 字体

- 正文/标题：`IBM Plex Sans Variable`（自托管）；中文回退 PingFang / 微软雅黑 / Noto Sans CJK。
- 等宽：`IBM Plex Mono`，只用于**编码、时间、数字**，不用于标签。
- 字阶：11 / 12 / 14 / 16 / 20 / 24 / 28。正文 14，页面标题 24，主数字 28，最小 11。
- 标题 `letter-spacing: -0.01em`；正文行高 20px（14px 字号）。
- 数字 `font-variant-numeric: tabular-nums`；表格数字列右对齐。
- 标题 `text-wrap: balance`；说明 `text-wrap: pretty`。

## 4. 壳与导航

```
┌───────────────┬──────────────────────────────────────────────┐
│ 铭医 / 控制台   │  页面标题 24px + 一行事实 + 操作                │
│ 当前范围 D013  ├──────────────────────────────────────────────┤
│ 临床诊疗        │  一个主数据面（时间轴 / 表格 / 工作区）           │
│  医嘱工作台     │                                              │
│  术前访视       │  检查器 / 抽屉 / 表格                          │
│ 手术与收费      │                                              │
│ 质量与知识      │                                              │
│ 跳转 / 用户     │                                              │
└───────────────┴──────────────────────────────────────────────┘
```

- 侧边栏 232px，与页面同地面，1px 右边框；选中项 `#EEE` 圆角 pill；没有彩色左条。
- 分组标签 12px 句首大小写灰色；导航 32px 行高、16px 线性图标、10px 图标-文字间距。
- 默认**没有顶栏**；页面标题行承担上下文。手机 ≤860px 出现 52px 顶栏 + 全屏导航 sheet。
- 手机导航关闭时 `inert` + `aria-hidden`；打开时焦点进入当前项；ESC/关闭按钮归还焦点。

## 5. 页面框架

### 5.1 标题行

- `h1` 24/600；下面一行 14px `--muted`：日期、可用数、台次、取消、利用率、更新时间。
- 右侧只放真实操作：日期切换、导出、刷新。一个主操作，其余中性。
- 不写“本页展示……”“此界面用于……”；说明只写数据事实。

### 5.2 主数据面

- 手术排台：一间手术间一行，07:00–20:00 横向时间轴；左侧房间列 sticky；bar 24px 高、4px 圆角。
  - 已计划：浅青底 + 青边；进行中：实青底；已完成：灰底；已取消：斜线纹理。
  - 今天：1px 青线 + “现在”标签；只在 07:00–20:00 内显示。
  - 点击 bar 选中；右侧 320px 检查器显示时间、台次、病例、分级、7 日利用率。
- 顶部工具：楼层 tab（下划线 2px）、状态图例（图例就是 bar 本身缩小）、显示维护中开关。
- 表格：时间 / 手术间 / 台次·病例 / 状态 / 分级 / 操作；`aria-sort`；数字右对齐；表头 12px 灰色。

### 5.3 表格

- 表头 36px，12px 常规字重，灰色，无底色带，无大写。
- 单行 36–53px；两行 56–92px；数字列右对齐、tabular。
- 行分隔 1px `--rule`；没有斑马纹；选中行 `--active`。
- 空值用灰色破折号；真实 0 打印为 0。
- 超过 50 行用后端 limit 或分页；不渲染全部。

### 5.4 KPI（仅其他页）

- 一个容器，1px 竖线分隔；标签 14px 灰色在上，数值 24–28px 在下。
- 不加图标、不加 sparkline、不加彩色左边条；单位是更小的灰色后缀。
- 数字必须有来源与口径；没有数据的指标不画。

## 6. 状态

| 状态 | 规则 |
|---|---|
| 加载 | 最终布局 + 真实尺寸平灰条；不 shimmer、不位移；刷新保留旧值 |
| 空 | 保留框架与标题；一句说明 + 一个下一步；96px 虚线框 |
| 错误 | 失败块内部一句“什么失败 + 上次成功时间” + 重试；不用全屏横幅 |
| 部分 | 哪个房间失败就只标哪个房间；其余数据照常 |
| 成功 | 安静确认；不抢焦点；`aria-live=polite` |
| 权限 | 说明边界与申请路径；不隐藏整个页面 |

## 7. 图表

- 趋势 → 一条 2px 折线；不要柱+线双编码。
- 单序列不要图例；图例的色块必须是 mark 本身。
- 3–5 条横向网格；不画 y 轴线；基线可以略重。
- y 刻度 4–7 个，11–12px 灰色；x 标签 4–7 个，不旋转。
- 单色；主数据才上 accent；状态色只给状态。
- 悬停给精确读数；同时提供隐藏数据表（屏幕阅读器）。
- 事件要标注原因；参考线用 1px 虚线。
- 空数据画 0 线，不做假曲线。

---

## 8. 图标与图像

- 自绘 80+ 图标：24×24 网格、1.5px 描边、圆角端点；只用于导航、按钮、状态提示。
- 不在图标外套彩色圆/方；容器最多是中性灰 disc。
- 品牌标记：深石墨圆角方块 + 白色脉搏 + 青绿端点。
- 空态不放大插图；软件产品最强的图片是它自己的真实界面片段。
- 不用占位图、假仪表盘、emoji。

---

## 9. 动效

- 只做反馈：press / hover / focus / 弹层 / 行到达；app screen 不做入场表演。
- 100–150ms 反馈，150–300ms 状态变化，300–500ms 浮层；退出快于进入。
- 只动 transform / opacity；不用 `transition: all`；不做弹跳。
- `prefers-reduced-motion` 下保留状态变化，去掉位移。

---

## 10. 可访问性

- 跳过导航链接；全键盘可达；焦点环 2px accent + 2px offset。
- 图标按钮 `aria-label`；装饰图标 `aria-hidden`。
- 表格 `th scope`；可排序列 `aria-sort`；图表有隐藏数据表。
- 弹层有标题、焦点陷阱、ESC 关闭、关闭后归还焦点。
- 正文对比度 ≥4.5:1；UI 边界 ≥3:1；颜色不是唯一信息。
- Web 指针目标 ≥24×24；触控 ≥44×44；手机导航关闭时 `inert`。
- 表单 label 可见、错误内联、`aria-describedby`、聚焦第一个错误。

## 12. 运行与验收

```powershell
cd frontend-console
npm install
npm run dev          # http://localhost:5174（/api 代理到 127.0.0.1:8080）
npm run typecheck    # vue-tsc --noEmit，必须 0 错误
npm run build
```

验收：

1. 1440 / 1728 / 1024 / 390 四档截图；390 无横向滚动。
2. 控制台零 error / warn。
3. 键盘：跳过导航 → 导航 → 日期 → 时间轴 bar → 检查器 → 弹层 → ESC。
4. 三态：加载（平灰条）/ 空（虚线框）/ 错误（块内重试）。
5. 深色模式独立检查对比度，尤其是分组带、表格行、状态 pill。
6. 每轮只修最严重的 3 个问题，最多 3 轮。

## 13. 当前已知边界

- 手术排台接口返回排台全字段（`sequence` / `status` / `cancelReason` / 房间与时间），但**不含术式、术者、患者号**。
  前端 `api/types.ts` 已声明 `operationName?` / `surgeon?` / `patientNo?`，页面用 `v-if="hasOperationName"` 条件渲染术式列；
  字段缺失时显示「第 N 台 + 病例号」，不编造。
  下一步是在 clinical 服务补**排台聚合 DTO**（join `surgery_case` 与 `visit` 快照），这是本页从「可用」到「完整」的关键。
- 表格 >50 行仍由后端 limit 控制，尚未前端虚拟化。
- 对比度：令牌按 WCAG AA 手工核对（2026-11-03）。控件边框已从 `--control`（1.48:1）拆出
  `--control-strong`（浅色 3.27:1 / 深色 3.70:1）。**自动化审计（axe / Lighthouse）仍未接入 CI。**
- 390px 下只有手术排台做了「表格变列表」；医嘱、术前访视、术中收费、麻精专册、病案首页 5 张表仍是
  横向滚动的桌面表格，待补。
- 全平台**没有行级数据权限**：网关注入 `X-Org` / `X-Dept`，但各服务尚未据此过滤。这属于后端待办，
  不能靠前端隐藏解决。

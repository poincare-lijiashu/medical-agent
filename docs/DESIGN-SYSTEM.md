# 铭医 MedAssist · 设计系统（控制台）

> 适用：`frontend-console/`（对接 `/api/v2` 的临床控制台）。
> 目标不是"好看"，而是**安静、可信、可核对**：医护连续工作 8 小时，界面不能抢注意力，
> 每个数字都要能回答"谁做的、什么时候、依据什么"。

---

## 1. 品牌

| 项 | 值 |
|---|---|
| 中文名 | 铭医（"铭"取铭刻、留痕之意） |
| 英文名 | MedAssist |
| 品牌标记 | 圆角方形"病历页 + 脉搏波"，深钴蓝底、白色脉冲线 |
| 标记文件 | `public/brand/mark.svg`（favicon 同源） |
| 登录主视觉 | `src/assets/brand/login-art.svg`（网格 + 同心圆 + 脉搏，无照片依赖） |
| 一句话 | 把「可核对」做成界面的一部分 |

**为什么自绘**：通用图标库与生图模板会让系统看起来像"任意一个后台"。
本项目需要的是医疗语义（医嘱、麻精、术前访视、病案首页），因此图标与插图全部自绘 SVG，
统一 24×24 网格、1.6px 描边、圆角端点；不使用 emoji 作为功能图标。

**关于 AI 生图**：本轮尝试调用平台生图接口，返回未授权（`code 1001`），因此改为
手写 SVG 插画。这样零外部依赖、可随主题换色、打印不失真，也更符合"自己的 UI"。

## 2. 色彩

浅色为主（诊室明亮环境、长文密集阅读）。深色为可选主题，令牌同名覆盖。

| 令牌 | 浅色值 | 用途 |
|---|---|---|
| `--bg` / `--bg-deep` | `#F2F4F7` / `#EAEDF2` | 页面底 / 更深一层 |
| `--panel` / `--panel-2` / `--panel-3` | `#FFFFFF` / `#FAFBFC` / `#F5F7FA` | 卡片 / 表头 / hover |
| `--sunken` / `--rail` | `#EEF1F5` / `#F7F8FA` | 下沉区 / 左侧导航 |
| `--line` / `--line-soft` / `--line-strong` | `#E3E8EF` / `#EDF0F4` / `#CBD3E0` | 发丝分隔 / 行内虚线 / 输入边框 |
| `--ink` / `--ink-2` / `--ink-3` / `--ink-4` | `#10151F` / `#445064` / `#6B7787` / `#8E99A8` | 主 / 次 / 辅助 / 微标签 |
| `--accent` / `--accent-ink` | `#1D5BD6` / `#123E94` | 唯一强调色 / 强调文字 |
| `--ok` / `--warn` / `--danger` | `#0F7A52` / `#96590A` / `#B42318` | 成功 / 待处理 / 高危 |
| `--brand` / `--brand-deep` | `#17439C` / `#0B1C3C` | 品牌标记与登录暗场 |

规则：

- 强调色占比 ≤ 10%，只用于主操作、当前选中、焦点环、关键链接。
- 状态**必须**同时有文字（`StatusPill` 自带文字与圆点），不允许只靠颜色。
- 层次靠 `panel → panel-3 → sunken` 与 1px 发丝线，不靠大阴影；阴影只用于浮层。
- 禁止：渐变按钮/文字、玻璃拟态、青蓝大色块顶栏、侧边彩色条、装饰性大插画。
- 唯一允许的渐变：登录右侧暗场（`brand-mid → brand-deep`），且不承载任何信息。

## 3. 字体与排版

- 拉丁与数字：`IBM Plex Sans Variable`（自托管，`@fontsource-variable`）；中文回退
  `PingFang SC / Microsoft YaHei / Noto Sans CJK SC`。
- 编码、时间、单号：`IBM Plex Mono`（400/500），形成"两种材料"的对比。
- 字号刻度：10（微标签）/ 11（元信息）/ 12（控件）/ 13（正文）/ 15 / 18 / 20 / 24（页标题）/ 30（登录）。
- 行高：紧凑 1.25，正文 1.55；标题 `text-wrap: balance`。
- 表格行高 34–42px，数字右对齐、`tabular-nums lining-nums`；金额只用
  `Intl.NumberFormat('zh-CN', {currency:'CNY'})` 展示，前端不做金额运算。
- 微标签（`.eyebrow`）：10px 等宽 + `letter-spacing: .12em`，仅用于真实分区，不做装饰编号。

---

## 4. 间距、圆角、阴影、层级

- 间距：4pt 栅格（4/8/12/16/20/24/32/40/48）。
- 圆角：3（徽标内）/ 5（小控件）/ 7（输入、按钮）/ 10（卡片、弹层）。
- 阴影：两层（环境 + 直射），不使用单层大雾阴影。
- 层级语义：sticky 10 < rail 20 < backdrop 40 < modal 50 < toast 60 < tooltip 70。

## 5. 组件规范

| 组件 | 文件 | 约束 |
|---|---|---|
| 图标 | `components/ui/AppIcon.vue` | 自绘 40+ 图标；`label` 为空时 `aria-hidden` |
| 弹层 | `components/ui/AppModal.vue` | ESC/遮罩关闭；打开后焦点进入；Tab 焦点陷阱；`role=dialog` |
| 状态徽标 | `components/ui/StatusPill.vue` | 状态码 → 中文 + 色调；未知状态显示原值，不猜 |
| 空态 | `components/ui/EmptyState.vue` | 必含"下一步做什么"，插画可选 |
| 反馈 | `components/ui/ToastHost.vue` | `aria-live=polite`，仅非阻断反馈；错误 7s、成功 4.2s |
| 患者上下文 | `components/domain/PatientVisitSearch.vue` | 病案号精确 / 姓名模糊二选一，避免后端 AND 查询必然为空 |
| 命令面板 | `components/ui/CommandPalette.vue` | ⌘/Ctrl+K；只列有权限的入口；↑↓/Enter/ESC |
| KPI | `components/ui/KpiCard.vue` | 指标 + 单位 + 事实说明 + 可选走势；不得使用假数据 |
| 走势线 | `components/ui/Sparkline.vue` | 纯 SVG，只表达方向，不替代精确读数 |

表单：错误内联在字段下方（不依赖 toast）；危险操作（撤销、停嘱、结算、回收）必须二次确认并写清后果。

## 6. 布局

```
┌───────────────┬──────────────────────────────────────────────────────────┐
│ 品牌 + 分组导航 │ 面包屑 · 班次 · 主题 · 刷新                                │
│ （可收起 68px） ├──────────────────────────────────────────────────────────┤
│  临床诊疗       │ 页标题 + 说明 + 主操作                                     │
│  手术与收费     │ 患者上下文条（检索 → 选中 → 就诊）                          │
│  质量与知识     │ 左：就诊/空间/手术间列表   右：明细、表单、表格、费用          │
│  用户 + 退出    │ 空 / 加载骨架 / 错误 / 无权限 四态齐备                       │
└───────────────┴──────────────────────────────────────────────────────────┘
```

- 页面最大宽 1680px，桌面优先；≥1500px 工作台显示三栏（列表 / 主区 / 检查器），
  1180–1499px 检查器折为四块横排，<1180px 单栏、导航收为图标栏。
- 顶栏右侧固定：实时时钟（真实系统时间）、命令入口、主题、刷新；不做假"系统正常"角标。
- 列多的表格使用 `.table--compact`：8 列以内可读，超过则合并列或进检查器。

### 6.1 工作台信息结构（医嘱）

1. 页头：标题 + 一句话职责 + 数据事实条（数据源 / 更新时间）。
2. 患者上下文条：检索 → 选中 → 过敏与档案状态。
3. KPI 条：本次医嘱、待执行/未计费、收费单金额、转送异常 —— 全部来自真实接口。
4. 三栏：就诊列表 / 医嘱主区（开立 + 明细 + 费用）/ 检查器（患者、费用构成、转送、审计边界）。
5. 检查器只读，不承载编辑；编辑一律走弹层并二次确认。

## 9. 本地运行

```powershell
cd frontend-console
npm install
npm run dev          # http://localhost:5174（/api 代理到 127.0.0.1:8080）
npm run typecheck    # vue-tsc --noEmit，必须 0 错误
npm run build        # 产物 dist/（不入库，由 .gitignore 排除）
```

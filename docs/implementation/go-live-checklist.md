## Go/No-Go 会议规则

- **参与人**：业务负责人、技术负责人、实施经理、安全合规、运维负责人；关键科室代表列席；
- **法定人数**：上述五类角色至少各 1 人在场，否则会议无效；
- **否决权**：业务负责人与技术负责人均有一票否决；安全合规对 S 类阻塞项有一票否决；
- **结论**：`GO` / `NO-GO` / `CONDITIONAL GO`（仅允许非阻塞项带条件，且必须指定关闭时间与责任人）；
- **记录**：结论、参与人、未关闭项、下次评审时间，归档到项目文档库并同步到上线工单。

## 上线后首个稳定期检查

- [ ] 无未关闭 P1/P2 事件；

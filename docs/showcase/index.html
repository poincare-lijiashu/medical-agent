ARCHITECTURE

系统架构

控制台与 AI 中台同源（单端口），/api/v2 由中台反代到网关； 网关负责租户解析、JWT 校验、身份头重写与入口限流；16 个领域服务各自持有独立 schema 与迁移历史，故障域互不牵连。

质量与已知边界

第三方评测综合得分 65.9 / 100；未整改项与原因完整保留在评测报告 §3， 没有从清单里移走。我们宁可公开「还没做到」，也不把待办写成已完成。

工程门禁是真的在跑

pre-push（分支 / 冲突 / 密钥 / ruff）+ GitHub Actions 11 个 job； Python 全量 2,140 项通过，Java 272 个测试文件 / 46,036 行； 迁移安全 lint 拦截破坏性变更。

安全默认值是「拒绝」

开发密钥、默认口令、未绑定实例码的许可、境外模型端点——任一命中生产环境即拒绝启动； 16 个服务在演示环境也只监听 127.0.0.1。

已知边界 · 医嘱执行态

医嘱状态机目前是 PLACED → CHARGED → CANCELLED，执行态落在护理执行表， 尚未回写为统一的 EXECUTED 状态。

已知边界 · 姓名类字段

证件号 / 手机号 / 住址已字段级加密，患者姓名与生日仍是明文列，列入整改清单。

已知边界 · 旧版 E2E

16 个旧版浏览器用例已显式 skip 并登记原因，当前门禁为 test_console_smoke_current.py（3 项真实浏览器冒烟）。

无真实患者数据

仓库与截图中的患者标识均为合成数据（P2026… / Gxx Patient xxxxx）， 签名人为测试构造值；历史中的病例原文已在上传前从 Git 历史彻底移除。

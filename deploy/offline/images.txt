# MedAssist 离网交付镜像清单（air-gapped image list）
#
# 用法：
#   1) 在有外网/有镜像站的机器上：./pull-and-save.ps1   （或 pull-and-save.sh）
#   2) 拷贝 images-doctor.tar / images-*.tar 到院内跳板机
#   3) 在院内主机：./load-and-push.sh <registry-host>
#   4) helm install 时用 --set imageRegistry=<registry-host>/medassist
#
# 规则：
#   * 每一行一个镜像（可带注释）；**必须写死版本 tag**，禁止 latest；
#   * 交付时把下面 "业务镜像" 的版本改为本次构建号（CI 产出）；
#   * 镜像总量约 4~6 GB（Milvus 与 OAP 占大头），按需裁剪：
#     - 不用 Milvus/Attu/etcd/MinIO 的科室级部署，可只搬前 4 个业务镜像 + PG + Redis + Nacos。
